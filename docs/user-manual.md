# 久延毘古（くえびこ）ユーザ操作手順書

## 1. 概要

本アプリは、ローカル PC で動作する「久延毘古（くえびこ）」です。
一定期間あなたの生存確認ができなかった場合に、事前に登録したメールアドレスへ金融情報、保険情報、サブスク、メモを自動送信します。

## 2. 動作環境

- Windows / macOS / Linux
- Go 実行環境があればビルド可能（`go build`）
- 配布バイナリ `app.exe` があれば Go 不要
- ネットワーク接続（メール送信時のみ必要）
- スマートフォン / タブレットのブラウザにも対応しています。画面幅に応じて自動でレイアウトが切り替わります。

## 3. 起動方法

### 3.1 バイナリを使用する場合

```powershell
# Windows PowerShell の例
.\app.exe
```

### 3.2 ソースから実行する場合

```powershell
go run .
```

### 3.3 環境変数 / .env ファイル

設定は以下の 2 通りで行えます。

1. **環境変数**を直接設定
2. **実行ディレクトリに `.env` ファイルを配置**

`.env` ファイルが存在する場合、起動時に自動読み込みされます。環境変数と `.env` の両方に値がある場合は、**環境変数が優先**されます。

`.env` ファイルの例：

```text
APP_PORT=8443
APP_TLS_AUTO=1
APP_CHECK_INTERVAL=1h
```

必要に応じて以下を設定できます。

| 環境変数 | 内容 | 既定値 |
|----------|------|--------|
| `APP_HOST` | 待ち受け IP アドレス | `127.0.0.1` |
| `APP_PORT` | 待ち受けポート番号 | `8080` |
| `APP_DATA_DIR` | データベース保存先ディレクトリ | `data` |
| `APP_CHECK_INTERVAL` | 生存確認切れの監視間隔 | `1h` |
| `APP_TLS_AUTO` | `1` にすると自己署名証明書を自動生成し HTTPS で起動 | 未設定（HTTP） |
| `APP_TLS_CERT` | サーバー証明書ファイルパス | 未設定 |
| `APP_TLS_KEY` | サーバー秘密鍵ファイルパス | 未設定 |
| `APP_ALLOWED_IPS` | アクセスを許可する IP 範囲（カンマ区切り） | 未設定（すべて許可） |

`APP_ALLOWED_IPS` の例：

```text
APP_ALLOWED_IPS=192.168.0.*,127.0.0.1
```

上記のように設定すると、`192.168.0.xxx` および `127.0.0.1` からのみアクセスできます。空欄の場合はすべての IP を許可します。

例：

```powershell
$env:APP_PORT = "3000"
$env:APP_CHECK_INTERVAL = "1m"
.\app.exe
```

HTTPS で自己署名証明書を自動生成する場合：

```powershell
$env:APP_TLS_AUTO = "1"
.\app.exe
```

LAN 内の他の端末からもアクセスさせたい場合（非推奨）：

```powershell
$env:APP_HOST = "0.0.0.0"
.\app.exe
```

起動後、ブラウザで以下を開きます。

```
http://localhost:8080
```

HTTPS を使う場合は `https://localhost:8080` となります。自己署名証明書のため、ブラウザでセキュリティ警告が表示されることがあります。

`APP_HOST=0.0.0.0` にした場合は、同一 LAN 内の他の端末から `http://<PCのIPアドレス>:8080` でアクセスできます。

## 4. 初回セットアップ

初回アクセス時は「初期設定」画面が表示されます。

1. パスワードを入力（8 文字以上）
2. パスワード（確認）を入力
3. 「作成」ボタンを押す

作成後、ログイン画面に遷移します。

## 5. ログイン / ログアウト

セットアップ時に作成したパスワードでログインします。
セッションは 24 時間有効です。

画面上部の「ログアウト」ボタンでログアウトできます。

パスワードを間違えるとログインが拒否されます。短時間に 5 回失敗すると、セキュリティのため 15 分間ログインがロックされます（429 応答）。解除方法は「Q. ログインがロックされた」を参照してください。

ロックはアクセス元 IP 単位でメモリ上にのみ記録され、15 分の経過で自動解除されます。アプリを再起動してもカウンタが消えるため、すぐにログインし直せます。

「設定」画面でパスワードを変更すると、現在のセッションは破棄されます。新しいパスワードで再度ログインしてください。

## 6. ダッシュボード（生存確認）

ログインするとダッシュボードが表示されます。

- 前回の生存確認日時
- 次回の確認期限
- 現在のステータス（正常 / 期限切れ / 作動済み）

### 6.1 生存確認を行う

「次回までの間隔（時間）」を指定し、「今すぐ生存確認」ボタンを押します。
これにより、確認期限が現在時刻から指定時間後に延長されます。

**重要**：定期的に本画面にアクセスし、生存確認を行ってください。期限を過ぎるとメールが送信されます。

### 6.2 秘密ページから生存確認を行う

ログインせずに更新したい場合は、「設定」画面の「秘密ページによる生存確認」でURLを発行します。表示されたURLにアクセスすると、現在設定されている確認間隔を保ったまま、生存確認日時だけが更新されます。更新後は完了画面が表示されます。

このURLを知っている人は誰でも生存確認を更新できるため、URLはパスワードと同じように秘密として扱い、ブックマークなど安全な方法で保管してください。URLが漏れた可能性がある場合は、設定画面の「URLを再生成」を押してください。以前のURLは直ちに無効になります。「無効化」で機能を停止することもできます。

秘密ページはログイン画面を経由しないため、他の端末からアクセスする場合は、サーバーを到達可能なアドレスで起動し、HTTPSを使用してください。

## 7. 金融情報の管理

画面上部の「金融情報」リンクから、作動時に送信するシークレットを管理します。

- **追加**：タイトルと内容を入力して登録
- **編集**：既存の情報を更新
- **削除**：不要な情報を削除
- **並べ替え**：PC では左端の `⋮⋮` をドラッグ＆ドロップ、スマートフォンやタブレットでは各行の `▲` `▼` ボタンで順番を変更できます。一覧画面の並び順はメール本文にも反映されます。

例えば、銀行口座や証券口座などの金融情報、各種サービスのユーザー名・パスワード、復旧用の情報を登録してください。

## 8. 保険情報・サブスクの管理

画面上部の「保険情報」または「サブスク」リンクから、金融情報と同じ項目（URL、ID、パスワード、追加項目、メモ）を登録できます。

## 9. メモの管理

画面上部の「メモ」リンクから、Markdown 形式のメモを管理します。

- **追加**：タイトルと Markdown 本文を入力
- **編集**：内容を更新
- **プレビュー**：ブラウザ上でレンダリング結果を確認
- **削除**：不要なドキュメントを削除

遺書、資産情報、連絡先、手順書などを登録できます。

## 9. 受信者の管理

画面上部の「受信者」リンクから、メール送信先を管理します。

- **追加**：名前とメールアドレスを入力
- **編集**：受信者情報を更新
- **削除**：受信者を削除
- **テスト送信**：この受信者宛にテストメールを送信

久延毘古（くえびこ）作動時には、ここで登録したすべてのアドレスへ、閲覧専用ページのURLが記載されたメールが個別に送信されます。情報そのものはメール本文や添付ファイルには含まれません。

### 9.1 メール送信テスト

SMTP 設定が正しいか、受信者にメールが届くかを事前に確認できます。

1. 「設定」で SMTP 設定を保存し、「メール送信を有効にする」にチェックを入れる
2. 「受信者」を開く
3. 対象の受信者の「テスト送信」、または「全受信者にテスト送信」を押す

テストメールは作動時と同じ形式で送信され、本文にはテスト用の閲覧URLが記載されます。

- テスト用URLは発行から **1時間** で自動的に失効します
- 「テスト用URLを失効させる」を押すと、その場で無効化できます
- SMTP 設定が未登録、または受信者が未登録の場合は送信されません
- 送信に失敗した場合は設定画面の SMTP 情報を確認してください

## 10. 設定

画面上部の「設定」リンクから、SMTP サーバーと IP アクセス制限を設定します。

### 10.1 SMTP 設定

メール送信に使用する SMTP サーバーを設定します。

| 項目 | 例 |
|------|-----|
| SMTP ホスト | `smtp.gmail.com` |
| SMTP ポート | `587`（Gmail） / `465`（TLS 直結） |
| SMTP ユーザー名 | メールアドレス（認証不要のローカルリレーを使う場合は空欄可。空欄のときは SMTP AUTH を行いません） |
| SMTP パスワード | アプリパスワードなど |
| 送信元アドレス | 送信元として表示するアドレス |
| TLS を使用する | 推奨（ポート 587 では STARTTLS、465 では TLS 直結） |
| メール送信を有効にする | チェックしないと作動しても送信されません |

### 10.2 閲覧者向けメッセージ

作動時に受信者が最初に目にするメッセージを登録できます。Markdown 形式で入力でき、内容は暗号化して保存されます。安全のため、Markdown 中の生の HTML タグは表示されず、`javascript:` などの危険なリンクは無効化されます。

設定画面の「閲覧専用ページの確認」から、実際の閲覧者と同じ構成を確認できます（管理者ログイン中のみ）。

### 10.3 IP アクセス制限

「許可する IP アドレスまたは範囲」に、接続を許可する IP を指定できます。

| 指定例 | 意味 |
|--------|------|
| `192.168.0.*` | `192.168.0.0/24` と同等 |
| `127.0.0.1` | ローカルホストのみ |
| `10.0.0.0/24` | `10.0.0.xxx` を許可 |
| `192.168.0.*,127.0.0.1` | 上記を両方許可 |

空欄にするとすべての IP からのアクセスを許可します。設定後は必ず「保存」を押してください。保存した内容は再起動なしで、次のアクセスから即時に反映されます。

**注意**: ここで IP 制限を設定すると、制限外の IP からはログイン画面すら表示されなくなります。誤って自分自身を締め出さないよう、必ず信頼できる IP を含めてください。

## 11. 久延毘古（くえびこ）の作動フロー

1. あなたが期限内に生存確認を行う → 何も起きません
2. 期限を過ぎると、バックグラウンドで検知
3. SMTP 設定が有効で、受信者が登録されていればメールを送信
4. 受信者ごとに異なる閲覧専用ページのURLが発行され、URLのみが記載されたメールが個別に送られる
5. 受信者がURLを開くと、まず管理者メッセージが表示され、その後カテゴリごとの情報を閲覧できる
6. 作動済みフラグが立ち、次回の生存確認まで再送信は行われない
7. 生存確認を行うと、発行済みの閲覧URLはすべて無効になる

## 12. セキュリティ上の注意

- 本アプリは基本的にローカル専用です。外部ネットワークに公開しないでください。
- `APP_HOST=0.0.0.0` を設定すると同一 LAN 内からアクセス可能になりますが、通信は暗号化されていない場合があります。LAN 公開する場合は `APP_TLS_AUTO=1` または正規の証明書で HTTPS を有効にしてください。
- `data` フォルダ内の `app.db` には暗号化された情報が入っていますが、暗号化キーも同ファイルに保存されています。`data` フォルダを他人に渡さないでください。
- HTTPS を使用する場合も、自己署名証明書のためブラウザ警告が出ます。信頼できる証明書を使う場合は `APP_TLS_CERT` / `APP_TLS_KEY` で指定してください。
- 強固な管理者パスワードを設定してください。
- SMTP パスワードは平文でデータベースに保存されます。信頼できる SMTP サービスのアプリパスワードを使用してください。
- `data` フォルダとデータベースファイルの権限は起動時に本人のみ（`0700` / `0600`）に修正されます。手動で `.env` に SMTP パスワード等を記載する場合は、あわせて権限を本人のみに制限してください（Linux/macOS: `chmod 600 .env`、Windows: ファイルのプロパティからアクセス権を本人のみに設定）。
- 受信者と送信元のメールアドレスは保存時に形式を検証しますが、送信可能なアドレスかまでは確認しません。作動前に「テスト送信」で到達確認を行ってください。

## 13. トラブルシューティング

### Q. ページが表示されない

- `app.exe` が起動しているか確認してください
- ブラウザで `http://localhost:8080`（または HTTPS の場合は `https://localhost:8080`、設定したポート）を開いているか確認してください
- ファイアウォールでブロックされていないか確認してください

### Q. メールが送信されない

- 「設定」で SMTP 情報が正しく入力されているか確認
- 「メール送信を有効にする」にチェックが入っているか確認
- 「受信者」が 1 件以上登録されているか確認
- SMTP サーバーの認証情報（アプリパスワード等）が正しいか確認
- 「受信者」画面の「テスト送信」で送信できるか確認（失敗時はフラッシュメッセージとログに理由が出ます）
- コンソールログにエラーが出ていないか確認

### Q. ログインがロックされた

短時間に 5 回ログインに失敗すると、その IP からは 15 分間ログインできなくなります（429 応答）。次のいずれかで解除できます。

1. **15 分待つ**
   - 最後の失敗から 15 分で自動的に解除されます。解除後に正しいパスワードでログインすれば、カウンタはリセットされます。
2. **アプリを再起動する（すぐに解除したい場合）**
   - ロック情報はメモリ上にのみ保持され、DB やファイルには保存されないため、再起動で即座に消えます。
   - 実行中のプロセスを停止し、`3. 起動方法` と同じコマンドで起動し直してください。
3. **別の許可 IP からアクセスする**
   - ロックは IP 単位のため、別端末や別の許可 IP からは即座にログインできます。

補足：

- ロック中も、ログイン済みのセッション、秘密ページ（`/checkin/<token>`）、閲覧専用ページ（`/view/<token>`）は影響を受けません。
- ロックはログイン時のみの制限です。生存確認メールの送信やデータには影響しません。
- 同じルーター（NAT）や同じ端末を共有している場合、同じ IP を使う他の利用者も一緒にロックされることがあります。

### Q. パスワードを忘れた

- 現状、パスワードリセット機能はありません
- `data` フォルダを削除すると初期設定からやり直せますが、登録データはすべて失われます

## 14. よくある使い方

1. 1 週間おきに PC を開く機会がある → 確認間隔を `168` 時間（7 日）に設定
2. 毎日確認したい → 確認間隔を `24` 時間に設定
3. 家族や信頼する友人にメールを送りたい → 受信者として複数登録
