# 久延毘古（くえびこ）ユーザ操作手順書

## 1. 概要

本アプリは、ローカル PC で動作する「久延毘古（くえびこ）」です。
一定期間あなたの生存確認ができなかった場合に、事前に登録したメールアドレスへログイン情報やドキュメントを自動送信します。

## 2. 動作環境

- Windows / macOS / Linux
- Go 実行環境があればビルド可能（`go build`）
- 配布バイナリ `kuebiko.exe` があれば Go 不要
- ネットワーク接続（メール送信時のみ必要）

## 3. 起動方法

### 3.1 バイナリを使用する場合

```powershell
# Windows PowerShell の例
.\kuebiko.exe
```

### 3.2 ソースから実行する場合

```powershell
go run .
```

### 3.3 環境変数 / .env ファイル

設定は以下の 2 通りで行えます。

1. **環境変数**を直接設定
2. **実行ディレクトリに `.env` ファイルを配置**

`.env` ファイルが存在する場合、起動時に自動読み込みされます。環境変数と `.env` の両方に値がある場合は、**環境変数が優先**されます。

`.env` ファイルの例：

```text
KUEBIKO_PORT=8443
KUEBIKO_TLS_AUTO=1
KUEBIKO_CHECK_INTERVAL=1h
```

必要に応じて以下を設定できます。

| 環境変数 | 内容 | 既定値 |
|----------|------|--------|
| `KUEBIKO_HOST` | 待ち受け IP アドレス | `127.0.0.1` |
| `KUEBIKO_PORT` | 待ち受けポート番号 | `8080` |
| `KUEBIKO_DATA_DIR` | データベース保存先ディレクトリ | `data` |
| `KUEBIKO_CHECK_INTERVAL` | 生存確認切れの監視間隔 | `1h` |
| `KUEBIKO_TLS_AUTO` | `1` にすると自己署名証明書を自動生成し HTTPS で起動 | 未設定（HTTP） |
| `KUEBIKO_TLS_CERT` | サーバー証明書ファイルパス | 未設定 |
| `KUEBIKO_TLS_KEY` | サーバー秘密鍵ファイルパス | 未設定 |
| `KUEBIKO_ALLOWED_IPS` | アクセスを許可する IP 範囲（カンマ区切り） | 未設定（すべて許可） |

`KUEBIKO_ALLOWED_IPS` の例：

```text
KUEBIKO_ALLOWED_IPS=192.168.11.*,127.0.0.1
```

上記のように設定すると、`192.168.11.xxx` および `127.0.0.1` からのみアクセスできます。空欄の場合はすべての IP を許可します。

例：

```powershell
$env:KUEBIKO_PORT = "3000"
$env:KUEBIKO_CHECK_INTERVAL = "1m"
.\kuebiko.exe
```

HTTPS で自己署名証明書を自動生成する場合：

```powershell
$env:KUEBIKO_TLS_AUTO = "1"
.\kuebiko.exe
```

LAN 内の他の端末からもアクセスさせたい場合（非推奨）：

```powershell
$env:KUEBIKO_HOST = "0.0.0.0"
.\kuebiko.exe
```

起動後、ブラウザで以下を開きます。

```
http://localhost:8080
```

HTTPS を使う場合は `https://localhost:8080` となります。自己署名証明書のため、ブラウザでセキュリティ警告が表示されることがあります。

`KUEBIKO_HOST=0.0.0.0` にした場合は、同一 LAN 内の他の端末から `http://<PCのIPアドレス>:8080` でアクセスできます。

## 4. 初回セットアップ

初回アクセス時は「初期設定」画面が表示されます。

1. ユーザー名を入力
2. パスワードを入力
3. パスワード（確認）を入力
4. 「作成」ボタンを押す

作成後、ログイン画面に遷移します。

## 5. ログイン / ログアウト

セットアップ時に作成したユーザー名とパスワードでログインします。
セッションは 24 時間有効です。

画面上部の「ログアウト」リンクでログアウトできます。

## 6. ダッシュボード（生存確認）

ログインするとダッシュボードが表示されます。

- 前回の生存確認日時
- 次回の確認期限
- 現在のステータス（正常 / 期限切れ / 作動済み）

### 6.1 生存確認を行う

「次回までの間隔（時間）」を指定し、「今すぐ生存確認」ボタンを押します。
これにより、確認期限が現在時刻から指定時間後に延長されます。

**重要**：定期的に本画面にアクセスし、生存確認を行ってください。期限を過ぎるとメールが送信されます。

## 7. ログイン情報の管理

画面上部の「ログイン情報」リンクから、作動時に送信するシークレットを管理します。

- **追加**：タイトルと内容を入力して登録
- **編集**：既存の情報を更新
- **削除**：不要な情報を削除

例えば、各種サービスのユーザー名・パスワードや、復旧用の情報を登録してください。

## 8. ドキュメントの管理

画面上部の「ドキュメント」リンクから、Markdown 形式のドキュメントを管理します。

- **追加**：タイトルと Markdown 本文を入力
- **編集**：内容を更新
- **プレビュー**：ブラウザ上でレンダリング結果を確認
- **削除**：不要なドキュメントを削除

遺書、資産情報、連絡先、手順書などを登録できます。

## 9. 受信者の管理

画面上部の「受信者」リンクから、メール送信先を管理します。

- **追加**：名前とメールアドレスを入力
- **編集**：受信者情報を更新
- **削除**：受信者を削除

久延毘古（くえびこ）作動時には、ここで登録したすべてのアドレスに情報が送信されます。

## 10. 設定

画面上部の「設定」リンクから、SMTP サーバーと IP アクセス制限を設定します。

### 10.1 SMTP 設定

メール送信に使用する SMTP サーバーを設定します。

| 項目 | 例 |
|------|-----|
| SMTP ホスト | `smtp.gmail.com` |
| SMTP ポート | `587`（Gmail） / `465`（TLS 直結） |
| SMTP ユーザー名 | メールアドレス |
| SMTP パスワード | アプリパスワードなど |
| 送信元アドレス | 送信元として表示するアドレス |
| TLS を使用する | 推奨（ポート 587 では STARTTLS、465 では TLS 直結） |
| メール送信を有効にする | チェックしないと作動しても送信されません |

### 10.2 IP アクセス制限

「許可する IP アドレスまたは範囲」に、接続を許可する IP を指定できます。

| 指定例 | 意味 |
|--------|------|
| `192.168.11.*` | `192.168.11.0/24` と同等 |
| `127.0.0.1` | ローカルホストのみ |
| `10.0.0.0/24` | `10.0.0.xxx` を許可 |
| `192.168.11.*,127.0.0.1` | 上記を両方許可 |

空欄にするとすべての IP からのアクセスを許可します。設定後は必ず「保存」を押してください。

**注意**: ここで IP 制限を設定すると、制限外の IP からはログイン画面すら表示されなくなります。誤って自分自身を締め出さないよう、必ず信頼できる IP を含めてください。

## 11. 久延毘古（くえびこ）の作動フロー

1. あなたが期限内に生存確認を行う → 何も起きません
2. 期限を過ぎると、バックグラウンドで検知
3. SMTP 設定が有効で、受信者が登録されていればメールを送信
4. 登録されているログイン情報とドキュメントがメール本文および添付ファイルで送られる
5. 作動済みフラグが立ち、次回の生存確認まで再送信は行われない

## 12. セキュリティ上の注意

- 本アプリは基本的にローカル専用です。外部ネットワークに公開しないでください。
- `KUEBIKO_HOST=0.0.0.0` を設定すると同一 LAN 内からアクセス可能になりますが、通信は暗号化されていない場合があります。LAN 公開する場合は `KUEBIKO_TLS_AUTO=1` または正規の証明書で HTTPS を有効にしてください。
- `data` フォルダ内の `kuebiko.db` には暗号化された情報が入っていますが、暗号化キーも同ファイルに保存されています。`data` フォルダを他人に渡さないでください。
- HTTPS を使用する場合も、自己署名証明書のためブラウザ警告が出ます。信頼できる証明書を使う場合は `KUEBIKO_TLS_CERT` / `KUEBIKO_TLS_KEY` で指定してください。
- 強固な管理者パスワードを設定してください。
- SMTP パスワードは平文でデータベースに保存されます。信頼できる SMTP サービスのアプリパスワードを使用してください。

## 13. トラブルシューティング

### Q. ページが表示されない

- `kuebiko.exe` が起動しているか確認してください
- ブラウザで `http://localhost:8080`（または HTTPS の場合は `https://localhost:8080`、設定したポート）を開いているか確認してください
- ファイアウォールでブロックされていないか確認してください

### Q. メールが送信されない

- 「設定」で SMTP 情報が正しく入力されているか確認
- 「メール送信を有効にする」にチェックが入っているか確認
- 「受信者」が 1 件以上登録されているか確認
- SMTP サーバーの認証情報（アプリパスワード等）が正しいか確認
- コンソールログにエラーが出ていないか確認

### Q. パスワードを忘れた

- 現状、パスワードリセット機能はありません
- `data` フォルダを削除すると初期設定からやり直せますが、登録データはすべて失われます

## 14. よくある使い方

1. 1 週間おきに PC を開く機会がある → 確認間隔を `168` 時間（7 日）に設定
2. 毎日確認したい → 確認間隔を `24` 時間に設定
3. 家族や信頼する友人にメールを送りたい → 受信者として複数登録
